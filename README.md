# Roman Urdu Sentiment Analyzer 🇵🇰

A Python-based NLP tool that analyzes Roman Urdu comments 
and detects positive, negative, and neutral sentiment percentages.

## About
Millions of Pakistanis write in Roman Urdu on social media 
platforms like Facebook, Daraz, and Twitter. However, existing 
sentiment analysis tools only support English. This tool bridges 
that gap by providing sentiment analysis specifically for 
Roman Urdu text.

## Features
- Bulk comment analysis from text file
- Detects Positive, Negative, and Neutral sentiment
- Calculates percentage for each sentiment
- Custom Roman Urdu word dictionary with spelling variations
- Lightweight and easy to use

## How to Use
1. Add your comments in comments.txt (one per line)
2. Run analyzer.py
3. View sentiment results instantly

## Tech Stack
- Python 3
- File Handling
- Natural Language Processing (NLP)
- Custom Roman Urdu Sentiment Dictionary
